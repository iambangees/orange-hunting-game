🍊 Orange Hunting Game

A fun and lightweight browser game where your mission is simple:

Hunt as many oranges as possible before time runs out!

Built with HTML, CSS, and JavaScript, the game is fast, responsive, and playable directly in your browser.

🎮 Play the Game

https://orange-hunting-game.vercel.app






✨ Features

- 🍊 Simple and addictive gameplay
- ⚡ Fast loading
- 📱 Mobile-friendly
- 🖥️ Desktop support
- 🎯 Score tracking
- ⏱️ Timer challenge
- 🎨 Clean and colourful interface
- 🌐 Runs completely in the browser


🕹️ How to Play
1. Start the game.
2. Click or tap on the oranges.
3. Collect as many as possible before the timer ends.
4. Beat your previous high score!

🚀 Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)


💻 Running Locally

Clone the repository:

```bash
git clone https://github.com/iambangees/orange-hunting-game.git
```

Go into the project folder:

```bash
cd orange-hunting-game
```

Open `index.html` in your browser

or use a local server:

```bash
npx serve
```

or

```bash
npx live-server
```
